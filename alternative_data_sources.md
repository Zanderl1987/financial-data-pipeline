# Alternative Free Financial Data Sources

| Data Source | Description of Available Data |
| :--- | :--- |
| **Alpha Vantage** | Provides historical and real-time time series data for stocks (intraday, daily, weekly), Forex, and Cryptocurrency. It also includes over 50 technical indicators and core fundamental data. Highly popular for its simplicity. |
| **Alpaca Markets** | A developer-first brokerage that offers a generous free API tier for real-time and historical US equity and crypto market data. It supports WebSocket streaming, making it ideal for algorithmic trading and paper trading environments. |
| **Finnhub** | Offers real-time stock quotes, institutional-grade company fundamentals, and unique alternative data such as news sentiment analysis, earnings calendars, and insider transactions across global exchanges. |
| **Polygon.io** | Known for high-performance, tick-level market data. Their free tier provides historical data and endpoints for stocks, options, and crypto, making it a favorite for developers needing precise market data (though free tier data is typically delayed). |
| **World Bank Open Data** | A massive repository of global macroeconomic, demographic, and development indicators covering over 200 economies. Excellent for sovereign risk analysis and long-term global macro modeling. |
| **IMF Data (International Monetary Fund)** | Provides access to global financial and economic statistics, exchange rates, directional trade statistics, and the World Economic Outlook (WEO) datasets. Highly valuable for cross-border macro research. |
| **Kenneth French Data Library** | The academic gold standard for quantitative researchers. Provides free access to Fama-French factor returns (3-factor, 5-factor), momentum factors, and industry portfolios used for asset pricing models and backtesting. |
| **EODHD (End of Day Historical Data)** | Offers extensive End-of-Day historical data with very broad global market coverage. Their free tier includes basic fundamentals, sentiment data, and economic events for thousands of global tickers. |
| **OpenFIGI (by Bloomberg)** | A free utility and API for mapping, identifying, and cross-referencing global financial instruments across all asset classes using the Financial Instrument Global Identifier (FIGI). Great for standardizing tickers. |
| **Marketstack** | A simple, clean REST API that provides worldwide stock market data. Their free tier is great for fetching historical, end-of-day (EOD), and basic intraday data across 72 global exchanges. |
